## Installation

_Follow these steps to set up the Multi-Language Translator on your local machine:_

1. _**Clone the repository**_
  ```sh
  git clone https://github.com/deepanshu414/translator.git
  ```
2. _**Navigate to the project directory**_
  ```sh
  cd translator
  ```
3. _**Create a virtual environment (optional but recommended)**_
  ```sh
  python -m venv venv
  source venv/bin/activate  # On Windows, use `venv\Scripts\activate`
  ```
4. _**Install the required packages**_
  ```sh
  pip install -r requirements.txt
  ```
## Usage

To run the Multi-Language Translator:

1. _Ensure you're in the project directory and your virtual environment is activated (if you're using one)._

2. _Start the Streamlit app_
  ```python
  streamlit run app.py
  ```
3. _Open your web browser and go to `http://localhost:8501` (or the address provided in the terminal)._

4. Use the interface to select your source and target languages, enter the text you want to translate, and click the "Translate" button.
