- Fast and accurate translations
- Easy-to-use API integration

## Prerequisites

Before you begin, ensure you have met the following requirements:

- Python 3.7+
- pip (Python package manager)
- Git (for cloning the repository)

## Installation

Follow these steps to set up the Multi-Language Translator on your local machine:

1. Clone the repository:
  ```sh
  git clone https://github.com/deepanshu414/translator.git
  ```
2. Navigate to the project directory:
  ```sh
  cd translator
  ```
3. Create a virtual environment (optional but recommended):
  ```sh
  python -m venv venv
  source venv/bin/activate  # On Windows, use `venv\Scripts\activate`
  ```
4. Install the required packages:
  ```sh
  pip install -r requirements.txt
  ```
## Usage

To run the Multi-Language Translator:

1. Ensure you're in the project directory and your virtual environment is activated (if you're using one).

2. Start the Streamlit app:
  ```python
  streamlit run app.py
  ```
3. Open your web browser and go to `http://localhost:8501` (or the address provided in the terminal).

4. Use the interface to select your source and target languages, enter the text you want to translate, and click the "Translate" button.
